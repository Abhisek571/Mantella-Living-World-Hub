# Mantella Living World - Integration Hub

The shared base of Mantella Living World: one MCM, one settings tab in Mantella's UI, the memory system and the action gates every module uses.

| Module | What it adds | Repository |
|---|---|---|
| Integration Hub | The base: this repository | [Mantella-Living-World-Hub](https://github.com/Abhisek571/Mantella-Living-World-Hub) |
| Relationships | Marriage, family ties and shared history | [Mantella-Living-World-Relationships](https://github.com/Abhisek571/Mantella-Living-World-Relationships) |
| Arousal | Arousal, appetite and temperament | [Mantella-Living-World-Arousal](https://github.com/Abhisek571/Mantella-Living-World-Arousal) |
| OStim Expansion | OStim scenes run by conversation | [Mantella-Living-World-OStim-Expansion](https://github.com/Abhisek571/Mantella-Living-World-OStim-Expansion) |
| Followers | Party orders through Nether's Follower Framework | [Mantella-Living-World-Followers](https://github.com/Abhisek571/Mantella-Living-World-Followers) |
| World | Fame, bounty, war side, quest outcomes, banter | [Mantella-Living-World-World](https://github.com/Abhisek571/Mantella-Living-World-World) |
| Knowledge | What each NPC plausibly knows | [Mantella-Living-World-Knowledge](https://github.com/Abhisek571/Mantella-Living-World-Knowledge) |
| Missives | Job posters who know their own jobs | [Mantella-Living-World-Missives](https://github.com/Abhisek571/Mantella-Living-World-Missives) |
| Mantella - Direct AI Connect | The patched Mantella.exe that the settings tab, memory and prompt rules run inside | [Mantella-Anthropic-API](https://github.com/Abhisek571/Mantella-Anthropic-API) |

| Feature | What it does |
|---|---|
| Settings tab | A Living World tab in Mantella's UI with the pages Status, NPCs, Player, Events, World Knowledge (with Knowledge installed) and Settings. Status: a module map with what needs attention, token use and the last prompt. NPCs: one page per NPC (pick a save and an NPC): the prompt preview, Personality (bio and voice overrides with presets), Background, Now, the facts history, Memories (search, edit, hide, unhide, delete, stories), Commands (release, forget, the record of what was hidden) and Knows about, with a red line where a belief and the game disagree. Player: your description and every override at once. Events: custom events and absolute commands per save. Settings: prompt rules and settings; overrides can be exported and imported as a zip. Other modules can add their own page (Knowledge's World Knowledge) |
| Memory | Each NPC remembers talks from their own point of view, with a feeling about you and long-term notes, within a fixed budget. Edit, add or delete memories in the tab, one at a time or per NPC |
| Action gates | Each NPC is offered only the actions that fit them (close, intimate, follower, guard, or a field such as nff=1 for Followers' party orders); hidden actions can't be run. If the hub can't tell, the gated action is not offered. Close means a friend or better, a party member, or engaged or married through Relationships; with Arousal, its own standing can make more NPCs close. Intimate (sex, undress, arousal actions) follows the Intimacy setting: NPC decides (default) offers them to every adult, who says yes or no as the person they are (a no shows on screen and is remembered); Lovers only needs a lover (rank 4), dating or closer through Relationships, or an Arousal open group. Always willing (Living World hotkey or the NPCs page) says yes and Intimacy: never says no in both; temperament never unlocks it. With a child in the talk no close or intimate action is offered to anyone. Stock Mantella's Inventory and Attack are offered to followers only (Settings tab, Gates for other actions); you can also add Attack and Inventory to Mantella's disabled_actions. Without Direct AI Connect nothing is filtered: sex, undress and marriage actions are offered to every NPC. Advanced Actions must be on in Mantella (Actions tab of http://localhost:4999/ui) for most Living World actions |
| Custom events | Events typed with Mantella's Add Custom Game Event hotkey (N by default) are listed per save and NPC on the Events page, to edit or take back; a memory already written from one is hidden (never deleted) and rewritten. Start an event with `silent:` and everyone present knows it happened but nobody answers it (a setting makes every event silent; `react:` then makes one narrated). Type `undo` as a custom event to take back your last one in this talk |
| Now and facts | Each NPC's prompt comes in order: their bio, background facts, how things are now, memories, absolute commands; where they differ the later part wins. Now is one short paragraph of their situation as they believe it, rewritten after a talk (never during one) when something changed: a custom event, a game fact, a command. Background comes from a dated facts history per save; marriage, home, follower and factions come from the game and text typed in the Hub never changes them. Edit, lock or reset Now, and add or end your own fact lines, on the NPCs page; Now can be turned off in Settings |
| World news | One log per save of what really happened: weddings, divorces, deaths, big fights, killings, spells that came to light and notable custom events (with World: murders, attacks and deaths of named people too). When an NPC next talks, what has reached them by then becomes a memory: seen if they were there, told by family or household about a day later, a rumour in their town after a few days, hearsay from the hold after a week for big events. What a hold believes about you (one short line) and "not acting like herself" for someone under your spell (mages can tell it is Illusion magic) come from it too. Each NPC page lists what they know, with forget and tell; an Absolute Command can name who forgets ("and everyone in Riverwood"). Children never hear of weddings or anything intimate; loading an earlier save sets later news aside |
| Basic bio | NPCs with no bio get a short one from their race, sex, job, place, hold and guild. Overrides always win. For an NPC with no bio you can paste their Nexus page or notes in the tab and press Write bio with AI; it keeps only the character info and lists what it assumed |
| Short bios | Each long bio (Mantella's or your override) is rewritten once into one short shape (Personality, Looks, Voice, History, Knows, Sample lines) without what Background already says, checked so no name or number is lost, and sent instead of the original from the next talk; else the original is sent. One helper request per NPC after a talk. Your files are never changed unless you press Write short bios into my override files (backed up first). Player page: Optimise all my overrides now. NPC page: original and short side by side, Use original, Optimise again. Switch: Settings > Short bios |
| Override presets | Per NPC, a Version dropdown (Default, then the presets saved for that NPC). Save as preset names a preset; Delete preset removes it (NPCs page, Personality) |
| Prompt rules | Each module adds short rule files to the system prompt |
| Quiet outfits | Mutes Mantella's equip and item events during scenes (needs OStim Expansion or Followers) and after loading screens |
| Absolute Command | A hotkey (G by default) during a Mantella conversation: type an order the NPCs in the talk must accept and act on, above every rule, their personality and memories. Kept per NPC until released (NPCs page, Commands) or for the hours it names; a command to forget something keeps each memory without that part (the original is hidden, never deleted). While it is in force the NPC counts as close and intimate for actions. Never works on children. Forgetting one thing is clean (they simply do not remember it); a command that wipes a whole period leaves a gap they notice. Release a command from the Living World hotkey on that NPC, or on the NPCs page: they remember and know it was a spell, forget the whole time, or keep believing |
| Console (experimental) | Off by default; turn it on and pick a key in the MCM (no key by default). During a Mantella conversation, type what should become real in the game ("give me 2000 gold", "make it rain", "set my one-handed skill to 50"). One helper request writes the console commands for it (needs the current Mantella - Direct AI Connect); a box lists every command and nothing runs unless you pick Run. The NPCs are then told the result as a fact. Needs [ConsoleUtilSSE NG](https://www.nexusmods.com/skyrimspecialedition/mods/76649) (without it the key does nothing) and Advanced Actions on in Mantella. The last runs are in the troubleshooting report |
| Temperament | Reserved, bold or forward per NPC, by hotkey or setup. Needs the Arousal module. The setup runs from the hotkey with nobody targeted. The Living World Setup power in the magic menu does the same as the hotkey |
| Mod facts | What other mods record about an NPC and you (a quest stage, a global, a faction rank, the relationship rank) becomes a short background line for that NPC, read from the game when they join a talk; nothing of the other mod is changed. Lines come from fact files, one per plugin, in Data\SKSE\Plugins\StorageUtilData\MantellaLivingWorld\modfacts\: user\ (yours, never overwritten), shipped\ (come with the Hub: Gerdur and Sigrid from Shadowman's NPCs) and generated\ (written by the Player page's Scan my dialogue mods button, or `py -3 tools/modfacts_generate.py --mo2 <MO2 folder>`: it reads your installed plugins and quotes the mod's own lines, at no cost; under Mod Organizer 2 the files go to the instance's overwrite folder, without it to Data; they are used only while Use scanned mod facts (experimental) is on, off by default; Show the last scan result shows the last table). For one plugin, user beats shipped beats generated. A file whose plugin is not installed is ignored. At most 6 lines per NPC, 160 characters each; shown read-only on the NPCs page (Background) with the mod named. Check files with `py -3 tools/modfacts_check.py --mo2 <MO2 folder> --folder <modfacts folder>` |
| Troubleshooting | MCM page that writes a report for bug reports, and an optional debug log |
| Update check | Every 3 days by default (set the number of days, 0 = off), asks Nexus's public API whether an installed module has a newer version and marks it on the module map. Only the mods' Nexus IDs are sent, with no account or key. On by default only until Living World has been in use long enough to be sure it has no bugs left; after that it will be off by default |

Requires: [Mantella](https://www.nexusmods.com/skyrimspecialedition/mods/98631) 0.14, [Mantella - Direct AI Connect](https://github.com/Abhisek571/Mantella-Anthropic-API), [powerofthree's Papyrus Extender](https://www.nexusmods.com/skyrimspecialedition/mods/22854), [PapyrusUtil](https://www.nexusmods.com/skyrimspecialedition/mods/13048), [Papyrus MessageBox - SKSE NG](https://www.nexusmods.com/skyrimspecialedition/mods/83578), [MCM Helper](https://www.nexusmods.com/skyrimspecialedition/mods/53000), [SkyUI](https://www.nexusmods.com/skyrimspecialedition/mods/12604), SKSE. The modules are optional; each needs only this hub. Mantella's Advanced Actions should be on.

Build: `py -3 tools/build.py` builds every module (`--only hub` for this one). Tests: `py -3.11 server/tests/test_<name>.py server`.
