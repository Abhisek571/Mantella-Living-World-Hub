# Mantella Living World - Integration Hub

The shared base of Mantella Living World. Modules plug into it; each needs only the hub.

| Module | Repository |
|---|---|
| Integration Hub | [Mantella-Living-World-Hub](https://github.com/Abhisek571/Mantella-Living-World-Hub) |
| OStim Expansion | [Mantella-Living-World-OStim-Expansion](https://github.com/Abhisek571/Mantella-Living-World-OStim-Expansion) |
| Arousal | [Mantella-Living-World-Arousal](https://github.com/Abhisek571/Mantella-Living-World-Arousal) |
| Relationships | [Mantella-Living-World-Relationships](https://github.com/Abhisek571/Mantella-Living-World-Relationships) |
| Followers | [Mantella-Living-World-Followers](https://github.com/Abhisek571/Mantella-Living-World-Followers) |

| Part | What it does |
|---|---|
| Quiet outfits | Mutes Mantella's equip/item events during scenes and after loading screens |
| Temperament | Reserved / bold / forward per NPC, hotkey and setup |
| Troubleshooting | MCM page: writes a report for bug reports, optional debug log |
| Settings | One MCM for the hub and its modules |

Requires: [Mantella](https://www.nexusmods.com/skyrimspecialedition/mods/98631)
